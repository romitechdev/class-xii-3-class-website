# Class XII-3 Website

Class website for XII-3 with a confession board, video gallery, and class information pages.

## Features

- Confession board (`confess.html`)
- Video gallery (`vidio.html`)
- Class information and announcements
- Maintenance page (`maintenance.html`)
- SEO-friendly with `robots.txt` and `sitemap.xml`

## Tech Stack

- HTML
- CSS
- JavaScript

## Project Structure

```
.
├── index.html
├── confess.html
├── vidio.html
├── maintenance.html
├── robots.txt
├── sitemap.xml
└── assets/
```

## Getting Started

Open `index.html` in a browser.
